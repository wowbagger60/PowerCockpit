## Voraussetzungen

IP-Symcon ab Version 8.2. Ab 9.1 kann die Kachel zusätzlich im Vollbild-Modus angezeigt werden.

## Installation

Über den Module Store oder im Module Control mit der URL
`https://github.com/wowbagger60/PowerCockpit`.

## Entwicklung

`preview.html` direkt im Browser öffnen. Die Vorschau zeigt die Kachel mit
Beispieldaten und Schaltern für Theme, Phasenanzahl, sichtbare Gruppen,
Leistungsrichtung und Sprache. Sie ersetzt keinen Test in der echten
Symcon-Visualisierung.
