# PowerCockpit

[Deutsch](README.de.md) | English

IP-Symcon library by Ueli Schweizer / Cassanis Automation.

| Module | Description |
|---|---|
| [PowerCockpit](PowerCockpit/README.md) | HTML tile with gauges for power, current and voltage of a single- to three-phase connection |

> **Beta version.** Testers with PV systems, batteries or other bidirectional
> sources are very welcome. The test guide (in German) is in
> [TESTING.md](TESTING.md), feedback in the
> [forum thread](https://community.symcon.de/t/tile-powercockpit-kachel-fuer-leistung-strom-und-spannung-beta-tester-mit-pv-oder-batterie-gesucht/144828).

## Requirements

IP-Symcon 8.2 or later. From 9.1, the tile can also be shown in fullscreen mode.

## Installation

Via the Module Store, or in Module Control with the URL
`https://github.com/wowbagger60/PowerCockpit`.

## Development

Open `preview.html` directly in a browser. It shows the tile with sample data
and buttons for theme, number of phases, visible groups, power direction and
language. The preview does not replace a test in the real Symcon visualization.
